FONTLOG for Galabir
===================

This file provides detailed information on the Galabir font software.
This information should be distributed along with the Galabir fonts
and any derivative works.


Basic Font Information
----------------------

Galabir is a readable Glagolitic typeface for Ukrainian and other
Cyrillic Slavic languages (Bulgarian, Serbian, Belarusian, Macedonian,
Montenegrin).

Modern Glagolitic fonts are hard to read in running text: most have no
ascenders or descenders, no distinction between uppercase and lowercase,
and many letters look too similar. Galabir follows the Latin-script model,
where the two cases come from different writing styles:

- uppercase is based on Angular (Croatian) Glagolitic;
- lowercase is based on Round (Bulgarian) Glagolitic;
- ascenders, descenders and tails are borrowed from Glagolitic cursive.

Glagolitic shapes are mapped to Cyrillic code points, so the font is typed
with an ordinary Cyrillic keyboard. Latin letters, digits and punctuation
are inherited from League Spartan.

Style: Light (300). Formats: TTF, WOFF2.
